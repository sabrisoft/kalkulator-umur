# Kalkulator Umur (Age Calculator)

Sebuah aplikasi web ringkas untuk mengira umur pengguna berdasarkan tahun lahir yang dimasukkan. Dibina menggunakan HTML, CSS dan JavaScript sahaja tanpa sebarang pustaka luaran.

## Ciri-ciri Utama (Features)

- **Pengiraan Automatik:** Mengambil tahun semasa secara automatik dari sistem peranti pengguna.
- **Validasi Input:**
  - Memastikan input tahun lahir adalah sah (bukan sifar, negatif, atau kosong).
  - Menghalang kemasukan tahun lahir yang melebihi tahun semasa.
- **Reka Bentuk Responsif:** Antara muka pengguna (UI) yang kemas, minimalis, dan mudah dibaca pada pelbagai saiz skrin.
- **Sokongan Bahasa Melayu:** Keseluruhan aplikasi diterangkan dan ditulis dalam Bahasa Melayu.

## Teknologi yang Digunakan (Technologies Used)

- **HTML5:** Struktur kandungan laman web.
- **CSS3:** Penggayaan gaya dan reka bentuk responsif (termasuk kelas ralat).
- **JavaScript (Vanilla):** Logik pengiraan umur, manipulasi DOM, dan sistem pengesahan (validation).

## Cara Penggunaan (How to Use)

1. Muat turun atau klon repositori ini ke dalam komputer anda.
2. Buka fail `index.html` dengan mana-mana pelayar web (seperti Google Chrome, Mozilla Firefox, Microsoft Edge, atau Safari).
3. Masukkan tahun lahir anda (contoh: `2000`) di petak input.
4. Klik butang **Kira**.
5. Keputusan umur anda akan dipaparkan serta-merta di bahagian bawah butang tersebut.
